# RoboCam product notes

RoboCam is a USB iPhone or iPad webcam with an optional LiDAR depth view. The
main path is intentionally short: install once, connect and trust the phone,
open RoboCam, and select the camera on the computer.

The desktop UI should keep USB automatic, microphone forwarding off by default,
and manual network connection in advanced controls. Setup may install normal
dependencies, but it must not bypass the OBS macOS extension approval, phone
trust prompt, or operating-system permissions.
